# Наполнение справочника сотрудниками из кадровой выгрузки

Портал: [auto.su10.ru](https://auto.su10.ru) → **Администрирование** → **Обмен справочниками** →
строка **Водители** → **Загрузить**.

Так заводят весь отдел разом — водителей, водителей КМУ, машинистов крана, погрузчика и
экскаватора. Доступ к серверу для этого не нужен, файл выбирается в браузере.

Формат — `.xlsx`, тот же, что у остальных справочников портала
([ADR 0073](adr/0073-directory-exchange-xlsx.md)). Прежняя загрузка файла `.json` снята: форматов
было два, а правил заполнения — одно, и держать ради одного справочника отдельный вход незачем.
Право тоже сменилось: раньше загрузка шла вместе с ведением водителей (`drivers.write`), теперь это
`directories.import` — **только администратор**. Заводить водителя по одному в
**Справочники → Водители** по-прежнему может и диспетчер.

Один сотрудник = один СНИЛС. Повторная загрузка того же файла ничего не дублирует и ничего не
меняет: строка с известным СНИЛС обновляет заведённого человека, и если данные те же — портал
покажет «без изменений». Отката у загрузки нет, поэтому первый шаг всегда предпросмотр.

## Порядок

1. **Выгрузите справочник** кнопкой «Выгрузить» — получите текущее состояние в том виде, в каком
   портал ждёт файл обратно. Пустой справочник выгружается пустым файлом: это и есть шаблон.
2. **Заполните файл**: дописывайте строки в конец, правьте существующие. Колонку
   «Идентификатор» не трогайте — у дописанных строк оставьте её пустой.
3. **Нажмите «Загрузить»** и выберите файл. Портал разберёт его и покажет отчёт: кого заведёт
   (поимённо), что изменит (по колонкам, «было → стало»), что оставит как есть и какие строки
   негодны. **База при этом не меняется** — рядом с числами стоит пометка «база ещё не изменена».
4. **Сверьте отчёт с выгрузкой на руках** и нажмите «Применить».

Если в файле есть хоть одна негодная строка, портал перечислит **все** ошибки сразу и не применит
ничего: исправляете файл один раз и грузите заново.

## Что в файле

Лист **«Данные»** — сам справочник, лист **«Справка»** — пояснения к колонкам (портал его не
читает). Первая строка — заголовки, по ним и идёт разбор: порядок колонок можно менять, ненужные
колонки можно удалить — то, чего в файле нет, загрузка не трогает.

| Колонка            | Обязательна | Что означает                                                                            |
| ------------------ | ----------- | --------------------------------------------------------------------------------------- |
| `Идентификатор`    | нет         | Служебная. Заполнена у выгруженных строк; у дописанных оставьте пустой                  |
| `ФИО`              | да          | «Фамилия Имя Отчество» одной ячейкой. Отчество может отсутствовать, фамилия и имя — нет |
| `СНИЛС`            | да          | Ключ человека. Принимается как напечатан: «112-233-445 95» или «11223344595»            |
| `Дата рождения`    | нет         | «ДД.ММ.ГГГГ». Принимается и ячейка-дата Excel                                           |
| `Телефон`          | нет         | Любое написание российского номера — портал хранит его одним видом                      |
| `Email`            | нет         | Рабочий адрес: на него уходит задание на рейс                                           |
| `Табельный номер`  | нет         | Печатается в путевом листе                                                              |
| `Должность`        | нет         | Должность строки: по ней портал понимает, водительские ли это категории                 |
| `Подразделение`    | нет         | Ложится комментарием к записи о работе                                                  |
| `Дата приёма`      | нет         | «ДД.ММ.ГГГГ»                                                                            |
| `Категории ВУ`     | нет         | Коды через точку с запятой: «B; C; CE»                                                  |
| `Серия ВУ`         | нет         | Реквизиты удостоверения. Если их нет, документ заводится с одними категориями           |
| `Номер ВУ`         | нет         | —                                                                                       |
| `Выдано`           | нет         | Дата выдачи удостоверения                                                               |
| `Действительно до` | нет         | Срок действия                                                                           |
| `Кем выдано`       | нет         | Подразделение ГИБДД                                                                     |
| `Комментарий`      | нет         | Заметка о водителе. Единственная колонка, где пустая ячейка означает «стереть»          |

**Незнакомая колонка — отказ.** Она означает файл по другому шаблону, и молча проигнорировать её
значило бы завести людей не тем, чем собирались.

## Что заводится

На каждую строку — физлицо, специализация «Водитель», запись о работе (должность, табельный номер,
подразделение) и, если есть категории, водительское удостоверение.

Если заполнены серия, номер и даты, они сразу попадают в удостоверение. Документ остаётся
«Не проверен», пока администратор не сверит его с оригиналом. Без реквизитов удостоверение
заводится только с категориями: серия, номер и сроки будут пустыми, и до их внесения водитель
**в отбор под машину не попадает** — без номера удостоверения путевой лист печатается
недействительным. Вносят их в карточке водителя заменой документа.

## Что загрузка меняет у заведённого человека

ФИО, дату рождения, телефон, email, комментарий, табельный номер, должность, подразделение и дату
приёма — тем, что стоит в файле. Правки видны в отчёте до применения, по колонкам.

Три правила, чтобы файл не затёр работу диспетчера:

- **колонки нет — поле не трогаем.** Кадровая выгрузка знает не про всё, и её молчание не означает
  «данных нет»;
- **ячейка пуста — то же самое** (кроме «Комментария»). Убирают значение в карточке водителя, а не
  пустой клеткой в файле;
- **значение то же — правки нет**, повторная загрузка того же файла ничего не меняет.

**Категории удостоверения только добавляются.** Если в файле их меньше, чем заведено, портал
предупредит о расхождении, но допуск не снимет: допуск к машине снимают документом, а не строкой
таблицы. Убирают категорию заменой удостоверения в карточке.

Удалить водителя файлом нельзя — строка, которой в файле нет, просто не трогается. Удаление
человека это учётное действие в справочнике.

## Машинисты: категории не заводятся

У машиниста в колонке «Категории ВУ» стоят категории **удостоверения тракториста-машиниста**, где
те же буквы закреплены за другими машинами: «D» у тракториста — колёсная машина свыше 110 кВт, а не
автобус. Портал их не заводит и говорит об этом в отчёте поимённо: «должность „Машинист
погрузчика“ не водительская: категории C, E относятся к другому удостоверению и не заведены».

Исключение — набор, невозможный у тракториста: подкатегории и составы с прицепом (B1, C1, CE,
DE). Это настоящие права, и они заводятся: так проходят машинисты крана, которые водят и грузовик.

Хранить категории тракториста-машиниста пока негде — такого вида документа в справочнике нет
([ADR 0049](adr/0049-staff-import-beyond-drivers.md), бэклог). Сами люди при этом заводятся:
карточка, должность и подразделение на месте, документ вносится позже.

## Частые отказы

| Что пишет портал                                 | Что произошло                                                                    |
| ------------------------------------------------ | -------------------------------------------------------------------------------- |
| «СНИЛС … не проходит проверку контрольной суммы» | Опечатка в одной цифре. Сверьте номер по 1С — контрольная сумма ловит именно это |
| «СНИЛС — 11 цифр, получено …»                    | В ячейке не номер: пусто, обрезано или лишний символ                             |
| «ожидается „Фамилия Имя Отчество“»               | В строке одно слово вместо ФИО                                                   |
| «Дата рождения — ожидается ДД.ММ.ГГГГ»           | В ячейке дата другого вида (например «27/07/1968»)                               |
| «такой даты нет в календаре»                     | Опечатка в числе или месяце — «31.02.2026»                                       |
| «та же запись уже описана строкой …»             | Две строки на одного человека — в выгрузке дубль                                 |
| «Колонки, которых у этого справочника нет: …»    | Файл собран по другому шаблону или это выгрузка другого справочника              |
| «Файл не похож на книгу Excel (.xlsx)»           | Выбран не тот файл                                                               |

Отдельно в отчёте — **не отказы, а предупреждения**: категории, которых нет в справочнике,
расхождение набора категорий с заведённым и должности, которым удостоверение не заводится. Они
применению не мешают, но прочитать их нужно.

## Персональные данные

Выгруженный файл содержит ФИО, СНИЛС и номера удостоверений живых людей. Его не пересылают почтой,
не кладут в общие папки и не хранят дольше, чем нужно для правки. Каждая выгрузка и каждая загрузка
пишутся в журнал действий портала.

## Другого пути нет

Заводить выгрузку с сервера нельзя: скрипт `seed:drivers` и шаг деплоя удалены — файл с
персональными данными на VPS не кладут. Портал остаётся единственным входом для файла; по одному
человека по-прежнему заводят формой в справочнике.
