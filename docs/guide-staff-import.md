# Наполнение справочника сотрудниками из кадровой выгрузки

Портал: [auto.su10.ru](https://auto.su10.ru) → **Справочники** → **Водители** → **Загрузить
выгрузку**.

Так заводят весь отдел разом — водителей, водителей КМУ, машинистов крана, погрузчика и
экскаватора. Доступ к серверу для этого не нужен: файл выбирается в браузере
([ADR 0047](adr/0047-drivers-import-from-portal.md)). Право то же, что у заведения водителя
руками (`drivers.write`): администратор, менеджер, диспетчер.

Один сотрудник = один СНИЛС. Повторная загрузка того же файла ничего не дублирует: уже заведённые
пропускаются. Отката у загрузки нет — заведённых удаляют по одному через справочник, поэтому
первый шаг всегда предпросмотр.

## Порядок

1. **Выберите файл** — портал сразу разберёт его и покажет отчёт: кого заведёт (поимённо), кого
   пропустит, у кого не будет удостоверения и какие категории он не узнал. **База при этом не
   меняется** — на кнопке предпросмотра стоит пометка «база ещё не изменена».
2. **Сверьте отчёт с выгрузкой на руках.** Число заведённых и состав — это то, что появится в
   справочнике.
3. **Нажмите «Завести водителей: N».** После этого список справочника обновится сам.

Если файл не разобран, портал перечислит **все** негодные строки сразу, а не первую из них:
исправляете файл один раз и грузите заново.

## Формат файла

JSON, кодировка UTF-8, до 500 строк за раз. Так его отдаёт выгрузка «Штатные сотрудники» из 1С,
приведённая к полям справочника:

```json
{
  "source": "Выгрузка 1С «Штатные сотрудники», отдел автотехники и СДМ. Снято 31.07.2026.",
  "note": "Произвольное примечание к файлу — в справочник не попадает.",
  "department": "Отдел автотехники и СДМ",
  "jobTitle": "Водитель",
  "drivers": [
    {
      "fullName": "Иванов Иван Иванович",
      "personnelNo": "00123",
      "jobTitle": "Машинист крана",
      "department": "Отдел автотехники и СДМ (ОП Химки)",
      "birthDate": "27.07.1968",
      "employedSince": "22.12.2015",
      "snils": "112-233-445 95",
      "email": "ivanov@example.ru",
      "categories": "B,B1,C,C1,BE,CE,C1E",
      "license": {
        "series": "99 39",
        "number": "482645",
        "issuedOn": "29.11.2024",
        "expiresOn": "12.07.2027",
        "issuedBy": "ГИБДД 7711"
      }
    }
  ]
}
```

| Поле                         | Обязательно | Что означает                                                                                                                         |
| ---------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `fullName`                   | да          | «Фамилия Имя Отчество». Отчество может отсутствовать; фамилия и имя — нет                                                            |
| `snils`                      | да          | Ключ человека. Принимается как напечатан: «112-233-445 95» или «11223344595»                                                         |
| `personnelNo`                | нет         | Табельный номер — печатается в путевом листе                                                                                         |
| `jobTitle`                   | нет         | Должность строки. Не указана — берётся общая из шапки файла, а если и её нет — «Водитель»                                            |
| `department`                 | нет         | Подразделение строки; ложится комментарием к трудовому отношению                                                                     |
| `birthDate`, `employedSince` | нет         | «ДД.ММ.ГГГГ» или «ГГГГ-ММ-ДД» — оба формата равноправны                                                                              |
| `email`                      | нет         | Рабочий адрес водителя: на него уходит задание на рейс. Пустая ячейка адрес не стирает                                               |
| `categories`                 | нет         | Категории строкой ровно как в источнике: «B,B1,C,C1,BE,CE,C1E»                                                                       |
| `license`                    | нет         | Полные реквизиты ВУ: обязательны `series`, `number`, `issuedOn`, `expiresOn`; `issuedBy` необязателен. Даты — в тех же двух форматах |

Поля `source` и `note` описывают происхождение файла и в справочник не попадают. `department` и
`jobTitle` в шапке — умолчания для строк, где своих нет: в выгрузке одного отдела должности
разные, и делить её на файлы по должностям не нужно
([ADR 0049](adr/0049-staff-import-beyond-drivers.md)).

**Лишних полей быть не должно.** Незнакомая колонка означает выгрузку по другому шаблону — портал
откажет с указанием ключа, вместо того чтобы молча её проигнорировать.

## Что заводится

На каждую строку — физлицо, специализация «Водитель», трудовое отношение (должность, табельный
номер, подразделение) и, если есть категории, водительское удостоверение.

Если строка содержит `license`, серия, номер, даты и орган выдачи сразу попадают в удостоверение.
Документ остаётся «Не проверен», пока администратор не сверит его с оригиналом. У старых выгрузок
без `license` удостоверение по-прежнему заводится только с категориями: серия, номер и сроки будут
пустыми, и их вносят через **«Заменить»** в карточке водителя.

## Email: единственное, что выгрузка правит у заведённого

Человека с уже известным СНИЛС повторная выгрузка пропускает — кроме адреса. Если в файле есть
`email` и он отличается от записанного, портал проставит его и назовёт таких людей отдельным
списком: «Проставлен email у заведённых». Так адреса раздаются всему справочнику одним файлом, а не
сотней открытых карточек.

Три правила, чтобы выгрузка не затёрла работу диспетчера:

- **колонки нет — адрес не трогаем.** Кадровая выгрузка про почту ничего не знает, и её молчание не
  означает «адреса нет»;
- **ячейка пуста — то же самое.** Убирают адрес в карточке водителя, а не пустой клеткой в файле;
- **адрес тот же — правки нет**, повторная загрузка того же файла ничего не меняет.

Неверный адрес отвергает всю выгрузку целиком, как и опечатка в СНИЛС: файл правят один раз, а не
выясняют ошибки по одной.

## Машинисты: категории не заводятся

У машиниста в колонке «категории» стоят категории **удостоверения тракториста-машиниста**, где те
же буквы закреплены за другими машинами: «D» у тракториста — колёсная машина свыше 110 кВт, а не
автобус. Портал их не заводит и говорит об этом в отчёте поимённо: «должность „Машинист
погрузчика“ не водительская: категории C, E относятся к другому удостоверению и не заведены».

Исключение — набор, невозможный у тракториста: подкатегории и составы с прицепом (B1, C1, CE,
DE) без единого незнакомого кода. Это настоящие права, и они заводятся: так проходят машинисты
крана, которые водят и грузовик.

Хранить категории тракториста-машиниста в системе пока негде — такого вида документа в
справочнике нет ([ADR 0049](adr/0049-staff-import-beyond-drivers.md), бэклог). Сами люди при этом
заводятся: карточка, должность и подразделение на месте, документ вносится позже.

## Частые отказы

| Что пишет портал                                      | Что произошло                                                                    |
| ----------------------------------------------------- | -------------------------------------------------------------------------------- |
| «СНИЛС … не проходит проверку контрольной суммы»      | Опечатка в одной цифре. Сверьте номер по 1С — контрольная сумма ловит именно это |
| «СНИЛС — 11 цифр, получено …»                         | В ячейке не номер: пусто, обрезано или лишний символ                             |
| «ожидается „Фамилия Имя Отчество“»                    | В строке одно слово вместо ФИО                                                   |
| «дата рождения — ожидается ДД.ММ.ГГГГ или ГГГГ-ММ-ДД» | В ячейке дата другого вида (например «27/07/1968»)                               |
| «СНИЛС повторяется в файле»                           | Две строки на одного человека — в выгрузке дубль                                 |
| «Unrecognized key: …»                                 | В файле лишнее поле: выгрузка сделана по другому шаблону                         |
| «не JSON»                                             | Выбран не тот файл (например .xlsx или .csv)                                     |

Отдельно в отчёте — **не отказы, а предупреждения**: «уже в справочнике (совпал СНИЛС)»,
«категорий нет в справочнике» (например «AM», «CE1» — уточняются по оригиналу удостоверения) и
«однофамильцы среди заведённых раньше» — последнее стоит проверить: чаще всего это тот же человек,
заведённый когда-то руками.

## Другого пути нет

Заводить выгрузку с сервера больше нельзя: скрипт `seed:drivers` и шаг деплоя удалены — файл с
персональными данными на VPS не кладут. Портал остаётся единственным входом для выгрузки; по
одному человека по-прежнему заводят формой в справочнике.
