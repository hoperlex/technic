## Размер бандла

Считается транзитивное замыкание синхронных импортов от точки входа (и от чанка маршрута, когда он
появится): `scripts/bundle-size.mjs`.

| Метрика                           | Значение     |
| --------------------------------- | ------------ |
| Чанков в замыкании первого экрана | 1            |
| JS первого экрана `/waste`        | 1767,5 КБ    |
| То же, gzip                       | **526,2 КБ** |

Собственного чанка у раздела нет: приложение собирается одним файлом, поэтому первый экран тянет и
справочники техники, и журнал путевых листов, и администрирование — всё, что пользователю в этот
момент не нужно. Критерий приёмки: уменьшить gzip первого экрана не менее чем вдвое (этап 5,
`React.lazy` по маршрутам и тяжёлым вкладкам).

## Запросы первого экрана

Замер живёт тестом `apps/web/test/first-screen-requests.test.tsx` — не наблюдением в devtools:
регрессия должна падать красным, а не замечаться случайно.

| Роль         | Запросов до первого действия | Какие                                                                         |
| ------------ | ---------------------------- | ----------------------------------------------------------------------------- |
| Диспетчер    | **6**                        | список, сводка, объекты, типы контейнеров, типы мусора, контрагенты-операторы |
| Штаб объекта | **5**                        | то же без операторов — исполнителя он не назначает                            |

Из шести запросов диспетчера четыре — справочники, и как минимум два из них (типы мусора, типы
контейнеров) нужны только форме, которую могут не открыть. Критерий приёмки: не более 3 запросов на
холодном кэше до первого взаимодействия.
